# 余物集 · 校园二手交易平台

一个本地运行的小型二手交易系统。不连外网、不要数据库安装、不用 npm，
双击就能跑。数据存在项目文件夹里的一个 `market.db` 文件中。

---

## 一、怎么运行

**双击 `启动.bat`**，等黑窗口出现下面这段字，浏览器会自动打开：

```
  校园二手交易平台已启动
  请在浏览器打开： http://127.0.0.1:5000
  演示账号： 小林 / 123456    老王 / 123456
  关闭这个黑窗口即可停止服务
```

第一次运行会自动装依赖，需要等一两分钟；之后再打开就很快了。

> 如果浏览器没有自动弹出，手动打开 Chrome / Edge，地址栏输入 `http://127.0.0.1:5000`

**关闭服务**：直接关掉那个黑色命令行窗口。

演示账号（密码都是 `123456`）：

| 账号 | 余额 | 用途 |
|---|---|---|
| 小林 | 5000 | 主要演示账号，也发布了几件商品 |
| 老王 | 3000 | 用来演示"换个身份看同一件事" |

## 二、功能一览

| 栏 | 能做什么 |
|---|---|
| 登录 / 注册 | 未登录时进入登录页，右下角"注册账号"，可上传头像 |
| 用户中心 | 改用户名、改密码、换头像、余额充值 |
| 首页 | 随机推荐商品，一次 12 件、点"加载更多"翻页、"换一批"重新推荐；右侧按价格区间 + 标签筛选；点击商品弹出详情窗 |
| 商品详情窗 | 显示全部信息，可"立即购买"或"讲价"（讲价会跳到消息栏） |
| 消息 | 左侧会话列表（带未读红点），右侧聊天；买家可发"改价申请"，卖家点"同意"后价格真的会变 |
| 我的商品 | 新增 / **编辑** / 删除 / 上下架；买来的商品会出现在这里，默认下架，可以再上架转卖 |
| 我的订单 | 买入、卖出两个子栏；每单有状态（待发货 / 待收货 / 已完成 / 已取消），卖家可发货、买家可确认收货或取消，显示成交价、商品快照、对方用户名头像、时间 |
| AI 淘好物 | 右下角悬浮球，点开是 AI 购物助手"小余"：用大白话描述需求（如"预算 3000 找台 iPad"），它会调用 DeepSeek 模型在站内搜索并推荐合适的在售商品，点卡片直接看详情下单 |

**使用前提**：把 DeepSeek 的 API Key 填进项目根目录的 `agent_config.json`（参考 `agent_config.example.json`），或者设置环境变量 `DEEPSEEK_API_KEY`。没填 key 时功能会提示如何配置，其他功能不受影响。

## 三、目录说明（每个文件是干什么的）

```
secondhand/
├─ 启动.bat              双击运行
├─ app.py                后端主程序：所有接口都在这里（登录、商品、消息、订单）
├─ models.py             数据模型：定义 5 张表的字段
├─ seed.py               演示数据：第一次运行时生成 3 个账号、22 件商品、3 笔不同状态的订单
├─ requirements.txt      Python 依赖清单
├─ market.db             数据库文件（自动生成，删掉就会重新生成演示数据）
├─ agent_config.json     AI 淘好物的配置：DeepSeek API Key 填在这里（不进 git）
├─ agent_config.example.json  上面那个的模板，组员 clone 后照着建
├─ venv/                 Python 虚拟环境（自动生成，不用管）
└─ static/
   ├─ index.html         页面结构：登录页、五个栏目、各种弹窗
   ├─ app.js             页面逻辑：调接口、切换栏目、发消息
   ├─ style.css          样式：改颜色就改文件开头的 :root 变量
   ├─ vue.global.prod.js Vue 框架本体（已经下到本地，断网也能用）
   └─ uploads/           上传的图片和自己生成的封面图
```

**想改界面文字** → 改 `static/index.html`
**想改颜色风格** → 改 `static/style.css` 开头那几行变量
**想改业务规则** → 改 `app.py`
**想加字段** → 改 `models.py`。老数据库会在启动时自动补上新列
（`app.py` 里的 `ensure_columns`），不用删库重来

## 四、五张表为什么这么设计

| 表 | 存什么 | 关键字段 |
|---|---|---|
| `users` | 账号 | 用户名唯一索引、密码哈希（不是明文） |
| `products` | 商品 | `tags` 存 JSON 字符串（如 `["数码","摄影"]`）、`status` 是 on/off |
| `conversations` | 会话 | 一件商品 + 一个买家 = 一个会话；`buyer_read_id` / `seller_read_id` 记两个人各自读到第几条 |
| `messages` | 消息 | `type` 分 text / offer / system，改价申请就是 `type=offer` |
| `orders` | 订单 | 除了成交价，还存了**商品快照**；`status` 是 pending / shipped / done / cancelled |

**订单为什么要存快照？**
因为商品会被买走、再上架、改标题。如果订单只记一个 product_id，
三个月后翻旧订单，看到的会是商品"现在"的样子，历史记录就被改写了。
所以下单那一刻，把商品名、图、描述、标签复制一份存进订单表。
——这也是为什么"编辑商品"不会影响已经成交的订单。

**未读为什么只用两个整数？**
每条消息存"谁看过了"要一张已读表，代价大。改成在会话上记
"买家读到第几条、卖家读到第几条"（`buyer_read_id` / `seller_read_id`），
判断未读就是一句 `id > 我读到的那条 且 不是我发的`。

## 五、答辩时可以讲的四个点

1. **商品流转闭环**
   一件商品可以被 A 卖给 B，B 再上架卖给 C，每次成交都留一条订单，
   而且订单里存的是成交当时的快照。这是二手平台和普通电商最本质的区别。

2. **订单不是一个布尔值，是一条状态机**
   状态只有四种：`待发货 → 待收货 → 已完成`，另外 `待发货` 可以直接 `已取消`。
   每次操作都先检查"当前状态允许不允许跳过去"，所以：
   未发货才能取消、发了货才能确认收货、已完成的订单不能再取消。
   代码里就是 `app.py` 的 `ORDER_FLOW` 那张表——**讲这一条比讲十个页面有说服力**。

3. **随机推荐 + 翻页会打架**
   如果每次请求都重新随机排序，第 2 页会出现第 1 页已经看过的商品。
   解决办法是给随机顺序一个"种子"，同一个种子算出的顺序永远一样，翻页才稳定；
   点"换一批"时换掉种子。这个坑我在自测时真的踩到了：
   最初把种子存在服务端的 session 里，结果 cookie 一丢顺序就变、翻页立刻重复，
   后来改成前端保存种子、每次请求带上，才彻底稳定。

4. **密码不是明文存的**
   用了 `pbkdf2:sha256` 哈希。可以现场打开 `market.db` 给老师看，
   `password_hash` 那一列是一串看不懂的字符，不是 `123456`。

## 六、演示顺序（三分钟走完一圈）

开两个浏览器窗口（一个普通窗口、一个无痕窗口），分别登录小林和老王，并排放着：

1. **小林**：首页翻两页 → 用"价格区间 + 标签"筛一次 → 点"换一批"
2. **小林**：点一件老王的商品 → 讲价 → 发一条"能便宜点吗" + 申请改价
3. **老王**：消息栏出现红点 → 打开会话 → 同意改价 → 商品价格变了
4. **小林**：回首页看到新价格 → 立即购买 → 余额减少
5. **老王**：我的订单 → 我卖出的 → 待发货 → 点"标记发货"
6. **小林**：我的订单 → 我买到的 → 待收货 → 点"确认收货" → 已完成
7. 顺手演示两个"拦得住"：已完成的订单不能再取消；别人不能编辑你的商品

这一圈走完，五个栏目全部覆盖，状态机也讲清楚了。

## 七、常见问题

**Q：打开是一片空白？**
按 F12 看 Console 有没有红色报错。多半是没登录或者服务没起来，
先确认黑色窗口还开着，地址是 `http://127.0.0.1:5000`。

**Q：提示端口被占用？**
说明已经开了一个。把之前那个黑窗口关掉再启动，或者改 `app.py` 最后一行的
`port=5000` 为 `5001`。

**Q：想清空数据重新来一遍？**
关掉服务，删除 `secondhand/market.db`，再启动。演示数据会重新生成，
包括你上传过的图片之外的所有内容。

**Q：手机怎么访问？（局域网演示）**
服务现在监听所有网卡（0.0.0.0）。启动后黑窗口会打印一个"局域网访问"地址
（形如 `http://192.168.x.x:5000`），保证手机和电脑连**同一个 Wi-Fi**，
手机浏览器输入那个地址即可。
- 第一次启动时 Windows 可能弹出防火墙询问，点"允许访问"；
- 没弹窗或连不上时，用管理员身份运行一次：
  `netsh advfirewall firewall add rule name="YuWuJi 5000" dir=in action=allow protocol=TCP localport=5000`

**Q：图片上传失败？**
只支持 png / jpg / gif / webp，单张不超过 8MB。

**Q：能不能换成 MySQL？**
可以。`app.py` 里只有一行连接配置：
`SQLALCHEMY_DATABASE_URI = "sqlite:///..."`，
换成 `"mysql+pymysql://用户名:密码@127.0.0.1:3306/market"` 即可，
再把 `requirements.txt` 加上 `pymysql`。
表结构不用改，因为是通过 ORM 写的。
